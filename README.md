# 📌 Python Assessment

## 📖 Overview
This repository contains a collection of Python assessment scripts that demonstrate proficiency in Python programming. The scripts cover various topics, including automation and problem-solving.

## 📂 Repository Structure
The repository consists of the following files:

- `question1.py` -  Check the strength of the password
- `question2.py` - Monitor the health of the CPU
- `question3.py` - Performing regular backups
- `README.md` - This document, providing an overview of the repository.

## 🚀 Getting Started

### ✅ Prerequisites
Ensure you have the following installed before running the scripts:

- **Python 3.x** ([Download Python](https://www.python.org/downloads/))

### 🔧 Installation

#### 📥 Clone the Repository
```sh
git clone https://github.com/amitjaswal28/PythonAssignment.git
cd PythonAssignment
```

## 🏃 Running the Scripts
Each script can be executed independently:

### ▶️ Running `question1.py`
```sh
python passwrdStrenth.py
```

### ▶️ Running `question2.py`
```sh
python CPUHealthMonitoing.py
```

### ▶️ Running `question3.py`
```sh
python backup.py
```

## 🛠 Troubleshooting

### ❌ Script Execution Issues
- Ensure Python is installed and added to the system PATH.
- Check for missing dependencies and install them using pip.
